## 🚀 Proyectos Destacados

### 1. Auditoría y Evasión: Laboratorio MitM (Man-in-the-Middle)
**Descripción:** Diseño y despliegue de un entorno de red interno aislado para simular escenarios de ataque y defensa. Ejecución de pruebas de concepto de ARP Spoofing para la interceptación y análisis de tráfico entre máquinas virtuales.
* **Tecnologías:** Kali Linux, Windows 10, VirtualBox, Bettercap, Wireshark.

### 2. Sistema de Gestión Logística Contenerizado
**Descripción:** Desarrollo de una solución de software orientada a la administración de distribución logística. La arquitectura cuenta con un front-end gráfico desarrollado a medida y un back-end de base de datos relacional aislado para garantizar la portabilidad.
* **Tecnologías:** Python (Tkinter), Docker, MySQL, Git.

### 3. Simulaciones de Infraestructura de Red Corporativa
**Descripción:** Diseño topológico e implementación de redes empresariales completas, asegurando la segmentación del tráfico, alta disponibilidad y enrutamiento dinámico eficiente entre múltiples sucursales simuladas.
* **Tecnologías:** Cisco Packet Tracer, IPv4/IPv6, OSPF, EIGRP, VLANs.

### 4. Hardware y Robótica Autónoma
**Descripción:** Programación y ensamblaje de un robot móvil capaz de navegar y evadir obstáculos de forma autónoma mediante el procesamiento de señales de sensores integrados.
* **Tecnologías:** Placa base Arduino Uno, C++, sensores de proximidad.
